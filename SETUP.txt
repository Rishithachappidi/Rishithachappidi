HOW IT WORKS ON GITHUB
The home page contains your photo, your name, and six linked door cards.
Each card opens its own real Markdown page within your repository.
Each page includes navigation and a Return to my profile link.
The résumé page links to your original PDF. Its filename is unchanged inside
its bytes; only the packaged filename was made clear and easy to link.
LinkedIn, GitHub, publication and email links are included.
Email opens the visitor's configured mail application.

DARK APPEARANCE
All custom artwork is dark. GitHub controls the surrounding page and Markdown
page colors. Set GitHub Settings > Appearance to a dark theme for a fully dark
view on your account. Visitors retain their own theme preferences.

HTML PREVIEW
The separate Rishitha-Dark-Door-Profile.html opens locally in a browser.
It embeds your real photo and résumé, and adds animated door transitions.
Click a door, browse its content, and use Back to profile to return.
The PDF can be opened or downloaded from its Résumé room.
The animation is preview-only; GitHub uses normal page navigation.
No hosting, portfolio setup, installation or API keys are needed.
